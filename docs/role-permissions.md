# 角色权限体系

权限采用“角色能力 + 数据范围”双层校验。角色能力决定能否进入功能或执行动作，数据范围决定同一功能中能看到、修改哪些记录。前端路由、菜单和按钮只是体验层，服务端 API 仍是最终权限边界。

## 数据范围规则

### 公开协作数据

- 失物招领、拼单集市和校园论坛对所有角色开放，以支持跨用户查看与协作。
- 新发布记录携带 `ownerId` / `authorId`，普通用户只能修改或删除自己的记录。
- 论坛坛主、管理员、高级管理员可管理论坛内全部帖子。
- 拼单参与者可以更新自己参与的人数；发起人仍负责编辑和删除拼单。
- 服务端会对共享快照写入做二次合并，普通用户提交的快照不能覆盖或删除其他用户的记录。
- 寻物发布者可确认打赏或自行领取；帮助者只能维护自己的线索记录。
- 拼单发起者可管理跑腿任务，接单人只能执行接单、送达和退出动作，不能修改小费。

### 系统控制台

- 普通管理员不再拥有 `admin` 功能模块、`system.settings` 能力或系统管理接口。
- 原 `/admin` 页面与 `/api/admin/*` 接口已移除。
- 高级管理员使用 `/system` 与 `/api/system/*` 访问唯一的系统控制台。
- “一键重置全部内容”仅高级管理员可执行，前端需二次确认，服务端还会校验固定确认短语 `重置全部内容`。
- 全量重置会清空业务数据、上传图片、所有头像、通知、AI 记录和审计历史；账号密码与系统配置保留，并新增一条本次重置审计。
- “还原拼单原始数据”仅高级管理员可执行，服务端校验确认短语 `还原拼单原始数据`；该操作只覆盖拼单及关联的支付、跑腿、争议和通知记录，不影响其他场景。

### 消息通知

- 每条通知保存唯一 `owner_user_id`，普通查询只返回当前账号的记录。
- 学生、班委、论坛坛主的 `scope=all` 请求直接返回 `403 NOTIFICATION_SCOPE_FORBIDDEN`。
- 管理员与高级管理员默认仍为本人范围，必须主动选择“全部用户”才调用管理视角。
- 管理视角只读：管理员不能借该视角修改、标记已读或删除其他用户的通知。

### AI 使用记录

- 每次需求解析、内容生成都会记录请求人、任务、模型、耗时、Token、请求编号和错误码。
- 默认查询 `scope=own`，只返回当前用户记录。
- 管理员与高级管理员可切换 `scope=all`；其他角色请求全部范围会返回 `403 AI_RECORD_SCOPE_FORBIDDEN`。

### 教室借用

- 学生和论坛坛主访问 `/api/shared/classroom` 返回 `403 FEATURE_FORBIDDEN`。
- 班委可创建和取消本人申请，新申请固定为 `pending`。
- 班委尝试自行把申请改为 `approved` 返回 `403 CLASSROOM_REVIEW_REQUIRED`。
- 只有管理员与高级管理员可以执行 `approved` / `rejected` 审批。

## 实现位置

- `server/permissions.js`：五类角色的能力、模块和默认数据范围。
- `server/index.js`：API 权限守卫、共享数据过滤与写入校验、通知和 AI 记录范围校验。
- `server/db.js` / `server/schema.sql`：通知、AI 调用日志及其归属字段。
- `src/stores/user.js`：将服务端权限同步到前端，提供 `can()` 与 `canAccess()`。
- `src/router/index.js`、`src/components/AppSidebar.vue`、`src/layouts/AppLayout.vue`：隐藏无权页面和导航入口。
- `src/stores/notify.js`、`src/views/NotificationsView.vue`：本人通知与管理员只读管理视角。
- `src/stores/aiRecord.js`、`src/views/AiRecordView.vue`：本人调用明细、统计和管理视角。
