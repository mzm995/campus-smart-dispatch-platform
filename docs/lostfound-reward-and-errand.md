# 失物悬赏与拼单跑腿流程

## 寻物打赏

发布寻物信息时可选择两种模式：

1. **设置打赏**：填写金额与可选说明。
2. **暂不打赏**：页面明确提示失主需要自行联系拾得者领取。

帮助者可以在寻物详情中提交“我提供线索”或“我已归还物品”，同时填写说明与联系说明。每一次提交只属于当前帮助者，发布者在详情中核验。

### 正式认领流程

失主发布寻物信息后，可以在匹配的招领帖中发起正式认领：

`发布寻物 → 打开关联招领 → 提交归属说明 → 招领人核验 → 失主确认领取 → 寻物与招领同时完成`

- 认领申请必须关联当前账号发布且尚未完成的寻物信息。
- 只有招领发布者可以审核认领申请。
- 核验通过后，只有认领申请人可以确认领取。
- 关联寻物有打赏时，确认领取会同时记录打赏金额；无打赏时直接完成线下领取。
- 招领发布者驳回后，申请人可以补充物品特征后重新申请。

### 有打赏

`等待发布者确认 → 发布者确认打赏 → 寻物完成 → 记录打赏金额与结算时间`

发布者确认时可以调整打赏金额。演示环境只记录结算状态，不发起真实支付。

### 无打赏

`帮助者提交线索 / 归还说明 → 失主自行联系 → 失主确认已领取 → 寻物完成`

无打赏时界面不展示打赏结算按钮，而是展示联系方式说明、站内联系引导和“我已自行联系并领取”确认入口。

### 取消与权限

- 帮助者可以撤回尚未处理的线索。
- 发布者可以关闭尚未处理的线索。
- 只有寻物发布者可以确认打赏或确认自行领取。
- 删除、编辑寻物信息仍按原有内容所有权校验。

## 拼单跑腿

发起拼单时可以附加跑腿任务，设置任务说明与小费。跑腿状态为：

`waiting/open → accepted → delivered → settled`

取消状态为 `cancelled`；接单人主动退出时任务回到 `open`。

### 接单

- 只有非发起人账号可以接单。
- 同一任务只能存在一个接单人。
- 任务已被接取、拼单截止或状态不匹配时，接单失败并给出明确提示。
- 乐观锁版本冲突会自动同步云端最新任务状态，避免静默覆盖接单人。

### 完成与结算

1. 接单人完成取货 / 配送后点击“已送达，等待确认”。
2. 发起人核验后点击“确认完成并结算”。
3. 系统记录结算金额，任务进入 `settled`，接单人收到通知。

发起人不能替接单人标记送达，接单人也不能自行结算小费。

### 取消边界

- 发起人可在待接单或配送中取消，取消后不结算小费。
- 接单人可在配送中退出，任务重新开放给其他人。
- 已送达但待确认时，接单人不能直接退出。
- 跑腿执行中不能删除拼单；发起人需先完成或取消跑腿任务。

## 权限与数据同步

跑腿和打赏状态保存在共享业务快照中。服务端按字段校验：

- 失物发布者可更新打赏、领取和完成状态。
- 帮助者只能追加或撤回自己的线索。
- 拼单发起者可管理完整跑腿状态。
- 接单人可以接单、标记送达或退出，但不能修改小费金额和任务说明。
- 其他用户不能修改已经接取或结算的跑腿任务。
