校园智能调度平台 - Windows x64 便携版
================================================

一、启动
1. 双击“启动校园智能调度平台-便携版.vbs”或“启动校园智能调度平台-便携版.bat”。
2. 程序会自动选择空闲端口并打开浏览器。
3. 停止服务请双击“停止校园智能调度平台-便携版.bat”。

本目录会优先使用 `runtime\node.exe`。如果运行时缺失、损坏或版本低于 Node.js 24，启动时会自动从官方源下载并校验安装，不要求目标电脑预先安装 Node.js、npm 或开发工具。

二、DeepSeek 模型
1. 使用高级管理员登录：方主管 / 2021000000 / 123456
2. 进入“系统管理 → DeepSeek 模型接入”。
3. 填入有效 API Key，加密保存后点击“测试真实连接”。
4. 若密钥无效、积分不足或网络不可用，系统会自动降级到本地规则引擎。

三、数据
- 数据库：server\data\campus-smart-dispatch-platform.sqlite
- API Key 加密主密钥：server\data\.secrets-key
- 请始终将上述两个文件一起备份，不要删除 .secrets-key，否则已保存的 API Key 无法解密。
- 便携版运行时只写入当前目录，不依赖系统级服务。

四、网络
- 后端仅监听 127.0.0.1，局域网中的其他设备无法直接访问。
- 多人云端共享需要把完整项目部署到联网服务器，而不是从 U 盘同时给多台电脑使用同一个 SQLite 文件。

五、故障排查
1. 双击“排查启动问题.bat”，查看控制台错误。
2. 查看 runtime-server.log 与 runtime-server-error.log。
3. 确保 U 盘/目录具有写入权限。
4. 确保电脑为 Windows 10/11 x64。
